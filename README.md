# taskflow-app
Создавайте задачи, ищите и фильтруйте их — всё хранится прямо на телефоне
TaskFlow — простой органайзер для повседневных задач. Приложение помогает ничего не забывать и держать все дела в одном месте: добавляйте задачи, редактируйте их и быстро находите нужные.

Ключевые функции:
• Добавление и редактирование задач на отдельном экране
• Поиск по задачам — нужная находится за секунду
• Фильтрация списка, чтобы видеть только то, что важно сейчас
• Экран настроек для удобной работы с приложением
• Хранение данных на телефоне: интернет не нужен, список остаётся после перезапуска

Преимущества: понятный и лёгкий интерфейс без лишнего, быстрый запуск, ничего не нужно настраивать, ваши задачи остаются только у вас на устройстве.

Для кого: для студентов, школьников и всех, кому нужен простой список дел без сложных сервисов и регистрации.
